    Inventory Api Service¶

    Inventory workflows (create/onboard/register/deploy/find devices).

    Utilities to onboard FTD devices (manual or ZTP), fetch/iterate device lists with progress, select devices interactively, and deploy changes (single/bulk).

    InventoryApiService ¶

    High-level helpers for inventory management and deploy flows.

    Attributes:

    Name Type Description
    api_client

    Authenticated SDK client.
    inventory_api

    Inventory API client.
    transaction_service

    Transaction helper.
    console

    Rich console for formatted output.

    xlsx_path, sheet_name=None, column_name=None

    Read device references from an Excel sheet.

    Prefers a column named devices; otherwise chooses the first text-like column. Returns a de-duplicated list of non-empty strings.

    Parameters:

    Name Type Description Default
    xlsx_path str

    Path to the Excel file.

    		 required
    sheet_name Optional[str]

    Optional sheet name. If omitted, the first sheet is used.

    		 None
    column_name Optional[str]

    Force a particular column to be used.

    		 None

    Returns:

    Type Description
    List[str]

    List of device reference strings.

    Raises:

    Type Description
    ClickException

    If no suitable text column can be found.

    resolve_references_to_devices ¶

    resolve_references_to_devices(
    references, require_online=True, interactive=True
)

    Resolve an iterable of user-provided references to unique device UIDs.

    Parameters:

    Name Type Description Default
    references Iterable[str]

    Device names, serial-like tokens, etc.

    		 required
    require_online bool

    If True, limit to ONLINE devices.

    		 True
    interactive bool

    If True, prompt when multiple matches exist.

    		 True

    Returns:

    Type Description
    Tuple[List[str], Dict[str, str], Dict[str, List[str]], List[str]]

    Tuple of: * uids: list of selected device UIDs * device_map: uid → display name (plus FMC record UID → name when available) * ambiguous_choices: ref → list of possible names (when not interactive) * unresolved: list of references that could not be mapped
