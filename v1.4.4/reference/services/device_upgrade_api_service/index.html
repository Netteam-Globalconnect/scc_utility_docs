    Device Upgrade Api Service¶

    Device upgrade workflows.

    Helpers for discovering available/compatible versions and performing FTD/ASA upgrades (single or bulk) with rich console feedback and transaction tracking.

    DeviceUpgradeApiService ¶

    Manage software upgrades for FTD and ASA devices.

    Encapsulates discovery of versions, compatibility checks, and starting upgrade transactions (single or bulk), with progress rendering.

    Attributes:

    Name Type Description
    api_client

    Authenticated SDK client.
    device_upgrade_api

    Device upgrade API client.
    transaction_service

    Helper for transaction polling and rendering.
    console

    Rich console for pretty output.

    get_all_ftd_versions ¶

    get_all_ftd_versions()

    Return all known FTD upgrade packages.

    Returns:

    Type Description
    List[FtdVersion]

    List of :class:FtdVersion package descriptors.
    Notes

    Uses a low-level call to fetch raw packages and maps them into SDK models for consistent downstream handling.

    update_upgrade_packages_cache()

    Refresh the server-side cache of FTD upgrade packages.

    Blocks until the refresh transaction completes.

    upgrade_ftd ¶

    upgrade_ftd(ftd_uid, ftd_name, ftd_version)

    Start an FTD upgrade and wait for completion.

    Parameters:

    Name Type Description Default
    ftd_uid str

    Device UID.

    		 required
    ftd_name str

    Device display name (for logs).

    		 required
    ftd_version FtdVersion

    Target package descriptor (must contain upgrade_package_uid).

    		 required

    Raises:

    Type Description
    RuntimeError

    If the response lacks a transaction ID.
    SystemExit

    If the transaction ultimately errors.

    upgrade_ftd_bulk ¶

    upgrade_ftd_bulk(
    ftd_uids,
    device_names,
    ftd_version_uid,
    delay_seconds=1,
    max_batch_size=50,
)

    Upgrade multiple FTDs in API-sized batches, sequentially.

    Ensures only one server-side transaction is active at a time and renders friendly progress + summary.

    Parameters:

    Name Type Description Default
    ftd_uids List[str]

    Device UIDs to upgrade.

    		 required
    device_names Dict[str, str]

    Mapping UID → Display name (for logs).

    		 required
    ftd_version_uid str

    Upgrade package UID to apply.

    		 required
    delay_seconds int

    Delay between batches (seconds).

    		 1
    max_batch_size int

    Max devices per API call (default 50).

    		 50
