    Command-line interface¶

    scc_utility¶

    SCC Utility — automate SCC tasks for cdFMC/FTD.

    Usage:

    scc_utility [OPTIONS] COMMAND [ARGS]...

    Options:

      API Credentials: [all_or_none]
    --region TEXT                 SCC region identifier (e.g., eu, us, ...).
    --api-token TEXT              SCC API access token. If omitted, you may be
                                  prompted at runtime.
  --help                          Show this message and exit.

    Subcommands

    • deploy: Deploy pending changes to a single FTD.
    • deploy-all: Deploy pending changes to all online FTDs in the tenant.
    • deploy-bulk: Deploy pending changes to multiple FTDs at once.
    • list-versions: List compatible software versions for a given FTD.
    • monitor-upgrade: Monitor a bulk upgrade transaction until completion.
    • upgrade: Upgrade a single FTD device.
    • upgrade-bulk: Upgrade multiple FTD devices in bulk.

    deploy¶

    Deploy pending changes to a single FTD.

    The device can be selected by --ftd-uid or by name with --ftd-name. If neither is provided, an interactive selector is shown.

    Examples: # Deploy by UID scc_utility deploy --ftd-uid 123456

    # Deploy by device name (fuzzy match)
scc_utility deploy --ftd-name NKA-123456

    Usage:

    scc_utility deploy [OPTIONS]

    Options:

      --ftd-uid TEXT   The UID of the FTD to deploy changes to.
  --ftd-name TEXT  Name of the FTD to deploy changes to (alternative to UID).
  --help           Show this message and exit.

    deploy-all¶

    Deploy pending changes to all online FTDs in the tenant.

    The command will: * Discover all devices of type CDFMC_MANAGED_FTD with state ONLINE. * Prompt twice for confirmation (safety check). * Trigger a bulk deploy if confirmed.

    Examples: # Deploy to all devices (with confirmation prompts) scc_utility deploy-all

    Usage:

    scc_utility deploy-all [OPTIONS]

    Options:

      --help  Show this message and exit.

    deploy-bulk¶

    Deploy pending changes to multiple FTDs at once.

    Prompts interactively to select multiple online FTD devices and then triggers a bulk deploy operation.

    Example: scc_utility deploy-bulk

    Usage:

    scc_utility deploy-bulk [OPTIONS]

    Options:

      --help  Show this message and exit.

    list-versions¶

    List compatible software versions for a given FTD.

    If --ftd-name is provided, resolves the UID automatically. Otherwise, falls back to interactive selection if no --ftd-uid is given.

    Args: ctx: Click context with base_url and api_token. ftd_uid: Optional UID of the target FTD. ftd_name: Optional device name to resolve UID from.

    Usage:

    scc_utility list-versions [OPTIONS]

    Options:

      --ftd-uid TEXT   The UID of the FTD to list compatible versions for.
  --ftd-name TEXT  The name of the FTD to list compatible versions for.
  --help           Show this message and exit.

    monitor-upgrade¶

    Monitor a bulk upgrade transaction until completion.

    Polls the SCC API at regular intervals and prints a live table of device upgrade status. Intended for use during bulk firmware upgrades.

    Args: ctx: Click context object (must contain base_url and api_token). transaction_id: ID of the transaction to monitor. poll_interval: Interval in seconds between status polls (default: 2.0).

    Usage:

    scc_utility monitor-upgrade [OPTIONS]

    Options:

      --transaction-id TEXT  The id of the transaction to monitor  [required]
  --help                 Show this message and exit.

    upgrade¶

    Upgrade a single FTD device.

    Performs optional deploy before upgrade and prompts the user to confirm before proceeding.

    Args: ctx: Click context with base_url and api_token. ftd_uid: UID of the target FTD. upgrade_package_uid: UID of the package to upgrade to. ftd_name: Optional device name to resolve UID automatically.

    Usage:

    scc_utility upgrade [OPTIONS]

    Options:

      --ftd-uid TEXT              The UID of the FTD to upgrade.
  --upgrade-package-uid TEXT  The UID of the upgrade package to use to perform
                              the FTD upgrade.
  --ftd-name TEXT             The name of the FTD to list compatible versions
                              for.
  --help                      Show this message and exit.

    upgrade-bulk¶

    Upgrade multiple FTD devices in bulk.

    Devices can be specified interactively or via an Excel file of references. Ambiguous matches are resolved interactively unless --non-interactive is provided.

    Args: ctx: Click context with base_url and api_token. upgrade_package_uid: UID of the upgrade package (prompted if omitted). devices: Path to Excel file with device references. sheet: Optional Excel sheet name. column: Optional column name. non_interactive: If true, skip prompts and ignore ambiguous matches.

    Usage:

    scc_utility upgrade-bulk [OPTIONS]

    Options:

      --upgrade-package-uid TEXT  The UID of the upgrade package to use to perform
                              the FTD upgrade.
  --devices XLSX              Path to an Excel file containing device names /
                              references (default column: 'devices')
  --sheet TEXT                Excel sheet name to read from (default: first
                              sheet).
  --column TEXT               Column name to read device references from
                              (default: auto; prefers 'devices').
  --non-interactive           Do not prompt to resolve ambiguous matches; skip
                              ambiguous rows instead.
  --help                      Show this message and exit.
